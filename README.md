## Ход работы

### 1. Проверка окружения

Для выполнения практической работы была проверена установленная версия Node.js с помощью команды:

```bash
node -v
```

![Версия Node.js](./screenshots/01-node-version.png)

### 2. Создание структуры проекта

В корне проекта был создан файл `index.html`, а JavaScript-код был вынесен в отдельный файл `js/main.js`.

JavaScript подключен к HTML с помощью тега:

```html
<script src="./js/main.js" defer></script>
```

Атрибут `defer` позволяет выполнить скрипт после загрузки HTML-документа.

![Структура проекта](./screenshots/02-project-structure.png)

### 3. Работа с переменными

Была создана переменная `userName` с помощью `let`:

```javascript
let userName = 'Артём'
```

Для вывода информации использовался метод `console.log()` и разные виды строк.

Пример шаблонной строки:

```javascript
console.log(`Привет, ${userName}!`)
```

### 4. Арифметические операции и приведение типов

Была создана строковая переменная:

```javascript
let price = '150.5'
```

При выполнении вычитания:

```javascript
price - 50
```

JavaScript автоматически преобразует строку `"150.5"` в число. Результат равен `100.5`.

При сложении:

```javascript
price + 10
```

получается строка `"150.510"`, так как оператор `+` при наличии строки выполняет конкатенацию.

При делении:

```javascript
let result = price / 2
```

значение `price` преобразуется в число, поэтому результат равен `75.25`.

Для удаления дробной части использован метод:

```javascript
Math.trunc(result)
```

Итоговое значение равно `75`.
